# UniAble

**An accessibility-first education platform designed to support students with disabilities.**

UniAble is a Richfield IT project exploring how voice interaction, accessible navigation, and assistive technologies can help students access educational services more independently.

## Current Development

The `Landing-Page-Prototype` branch contains the initial landing page, built manually using HTML, CSS, and JavaScript.

### Features

* Welcome screen and navigation options
* Voice sign-up and voice login entry points
* Email login and guest access entry points
* Responsive styling for mobile and desktop
* Accessibility-focused interface design

## Technology Stack

* HTML5
* CSS3
* JavaScript

## Development Approach

UniAble is being developed incrementally in Visual Studio Code. Individual screens will be built and tested before the application components, navigation, and backend services are integrated.

## Project Status

**In development.** The landing page is the initial UI prototype. Authentication, voice interaction, backend integration, and other application features will be implemented and tested in subsequent stages.
